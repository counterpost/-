# ワークアウトタイマー

「30秒運動 → 90秒休憩」を5セット、のような繰り返しインターバルタイマー。スマホのブラウザで動く PWA です。

## できること
- 区間(名前と秒数)を好きなだけ並べて、指定セット数くり返す
- 準備カウントダウン、最後の休憩をとばす
- 残り3秒のビープ、切り替わり音、バイブ、音声読み上げ
- 実行中は画面が消えないようにする(対応ブラウザのみ)
- プリセット保存(端末内に保存)
- ホーム画面に追加するとアプリとして起動、オフラインでも動く

## 使い方
GitHub Pages などで公開し、スマホで開いて「ホーム画面に追加」。

## ファイル
- `app.html` … 本体(編集はこちら)
- `build.sh` … `app.html` から `index.html` を生成
- `manifest.webmanifest`, `sw.js`, `icon-*.png` … PWA 用

## Android アプリ版(画面オフでも鳴る)
`android/` にあります。タイマー本体はアプリ側の常駐サービスで動き、区切りごとにアラームをセットするので、スリープ中でもアラーム音量でビープ・バイブ・読み上げします(マナーモードでも鳴ります)。

- push すると GitHub Actions が APK をビルドし、Releases の「latest-apk」に置きます
- スマホでその APK をダウンロード →「提供元不明のアプリ」を許可してインストール
- 署名鍵 `android/app/workout-timer.keystore` は個人配布用です(Play ストアに出すなら別の鍵を使ってください)

## おまけ: RTS「クリスタル戦線」
`rts/index.html` は、スマホのブラウザで遊べるリアルタイムストラテジーです(1ファイル完結、外部ライブラリなし)。

- クリスタルを採掘 → 家・兵舎・砲台を建設 → 剣士・弓兵・騎兵で敵の建物を全部壊せば勝ち
- 相性: 剣士→騎兵、騎兵→弓兵、弓兵→剣士に強い
- 敵 AI は難易度 3 段階。マップは毎回ランダム(左右対称)
- 操作: タップで選択/命令、ドラッグで画面移動、2本指で拡大縮小。PC は左クリック選択・右クリック命令
