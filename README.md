# 繰り返しタイマー

「30秒運動 → 90秒休憩」を5セット、のような繰り返しインターバルタイマー。スマホのブラウザで動く PWA です。

## できること
- 区間(名前と秒数)を好きなだけ並べて、指定セット数くり返す
- 準備カウントダウン、最後の休憩をとばす
- 残り3秒のビープ、切り替わり音、バイブ、音声読み上げ
- 実行中は画面が消えないようにする(対応ブラウザのみ)
- プリセット保存(端末内に保存)
- ホーム画面に追加するとアプリとして起動、オフラインでも動く

## 使い方
GitHub Pages などで公開し、スマホで開いて「ホーム画面に追加」。

## ファイル
- `app.html` … 本体(編集はこちら)
- `build.sh` … `app.html` から `index.html` を生成
- `manifest.webmanifest`, `sw.js`, `icon-*.png` … PWA 用
